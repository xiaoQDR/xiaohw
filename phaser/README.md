# 小黑屋：余火（Phaser 版）

这是小黑屋的完整 Web 发行版。Phaser 负责启动和页面生命周期；游戏运行时以仓库中的原版代码为权威基线，确保事件、数值、地图、战斗、星舰、结局和存档行为不在重构过程中丢失。

## 完整内容

- 原版生火、村庄、建筑、职业、交易和制作系统
- 原版行囊、负重、补给、程序化地图、地标和完整事件树
- 原版武器、弹药、状态、战斗、星舰、太空关卡、结局与周目继承
- 原版 LocalStorage 存档、导入导出、音频和多语言资源
- 手机竖屏与桌面浏览器自适应
- 刘海/挖孔屏与底部手势安全区适配
- 手机文字、触控热区、地图滑动和太空关卡方向键优化

`src/scenes/GameScene.ts` 保留了早期 Phaser 原型供后续逐模块迁移，但不再作为发行版入口。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建结果位于 `dist/`。
