# 小黑屋：余火（Phaser 版）

这是对仓库中经典极简文字冒险的 Phaser 3 + TypeScript 原生重构。原版代码只作为数值、剧情和行为对照，不参与游戏运行。

## 已迁移内容

- 生火、村庄、建筑、职业与资源生产
- 制作、荒野、地标、战斗和本地存档基础流程
- 手机竖屏与桌面浏览器自适应
- 刘海/挖孔屏与底部手势安全区适配
- 手机文字和触控热区优化

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建结果位于 `dist/`。
