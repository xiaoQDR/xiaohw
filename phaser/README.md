# 小黑屋：余火（Phaser 版）

这是对仓库中经典极简文字冒险核心循环的 Phaser 3 + TypeScript 重构版本。界面、输入、状态更新和荒野地图均由 Phaser 管理，不依赖旧版 jQuery DOM。

## 已实现

- 生火、添柴、拾取木材与冷却
- 村庄人口、建筑、职业分配和资源生产
- 工坊装备制作与荒野解锁
- 程序化显示的荒野地图、补给消耗、地标与随机遭遇
- 回合冷却战斗、战利品、倒下与返乡
- LocalStorage 自动存档
- 手机竖屏与桌面浏览器自适应

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建结果位于 `dist/`。
